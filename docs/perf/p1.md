# Perf report

Generated by `cargo xtask perf --idle-secs 60` on the release build.

**Machine:** Intel(R) Core(TM) Ultra 9 288V, 32 GB RAM, Microsoft Windows 11 Home build 26200

| Metric | Measured | Budget | Result |
|---|---|---|---|
| cold start to armed | 21.70 ms | ≤ 120 ms | pass |
| cold start to first frame | 39.10 ms | ≤ 200 ms | pass |
| pre-first-wake private | 1.86 MB | ≤ 10 MB | pass |
| idle private | 2.53 MB | ≤ 20 MB | pass |
| idle working set | 15.29 MB | ≤ 25 MB | pass |
| idle CPU per 60 s | 0.00 ms | ≤ 60 ms | pass |
| binary size | 0.81 MB | ≤ 8 MB | pass |
| head frame p95 | 0.44 ms | ≤ 0.5 ms | pass |

The head frame p95 is measured over the launch peek (about 60 frames: reveal, 1.2 s of Idle breathing at 30 fps,
retract). Across six shorter runs it ranged 0.30–0.46 ms, with one 0.58 ms outlier while other apps were busy, so it
sits close to the budget. Rendering is about 50 µs; most of the cost is `UpdateLayeredWindowIndirect` itself.

Idle working set rose from 7.3 MB (P0) to 15.3 MB. Most of that is shared system DLL pages (uxtheme, DWM, shell)
mapped by the head window, tray icon and dark menus; private memory is 2.5 MB.

## P1 acceptance (spec §8)

| Criterion | Result |
|---|---|
| Every visual state renders correctly at 100 %, 150 % and 200 % (`xtask snap`) | `cargo xtask snap` writes 27 PNGs plus `sheet.png` (all 8 states and the error flash × 3 scales). All states were also captured on screen at 150 % with `sohi --dev-states`. |
| Clicks on transparent pixels reach the window underneath; clicking never activates Sohi | Checked on screen in P1.4 (transparent pixel → window below; foreground unchanged after a click). The hooded ghost's gaps are alpha 0, unit-tested (`corners_and_gap_beside_hood_are_click_through`). |
| No taskbar button, not in Alt-Tab, stays above a normal window | `WS_EX_TOOLWINDOW \| WS_EX_TOPMOST \| WS_EX_NOACTIVATE`, unit-tested; topmost re-asserted on every reveal. |
| Reveal is a slide from off-screen; no pixels on a monitor to the right | Frame-by-frame capture shows a 260 ms slide in from the right with a fade. The window never moves: content is shifted inside the bitmap. **Not tested on two monitors** (only one display available). |
| Parked: window hidden, timer cancelled; CPU ≤ 60 ms/60 s; frame p95 ≤ 0.5 ms | Hidden and timer stopped on park (log shows `parked`); idle CPU 0.00 ms; frame p95 0.44 ms (see note above). |
| Cold start to first peek frame ≤ 200 ms; pre-first-wake RAM ≤ 10 MB | 39 ms; 1.9 MB private at armed, 2.5 MB after the peek. |

Differences from the spec's P1 scope:
- State cycling for development is a command-line flag (`--dev-states`) rather than debug hotkeys; global hotkeys
  arrive with P2.
- The head is the "hooded ghost" design chosen on 2026-11-22 (spec §1.1); its round eyes take the visor's role.
- The tray and head menus are always dark (spec §4.8, uxtheme ordinals).
