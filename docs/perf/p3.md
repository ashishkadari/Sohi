## Notes

**Binary size is 1.91 MB (1 913 344 bytes), up 1.07 MB from P2's 838 656 bytes.** That is the async HTTP stack: tokio
(current-thread runtime), reqwest with `native-tls` (Windows' own SChannel, so no TLS library is bundled), and
serde_json. The commit footer of `feat(app): stream replies into bubble` says the same +1.07 MB, but at that point the
real increase was 1.03 MB (1 866 240 bytes); the figure here is the correct total for the phase.

**Pill RAM** (release build, scratch config, `pill_ram.ps1` live run; no API key, so the turn failed with `MissingKey`):

| Point | Private | Working set |
|---|---|---|
| Before the pill | 2.13 MB | 11.80 MB |
| Pill shown, one turn sent | 3.76 MB | 22.75 MB |
| Pill hidden | 3.74 MB | 22.78 MB |
| Pill destroyed (300 s hidden, logged `pill destroyed after 300 s hidden`) | 3.63 MB | 24.13 MB |

Private bytes end 1.50 MB above the pre-pill value, within the 2 MB criterion. What stays is the runtime thread
(tokio, the shared HTTP client and its connection pool), which lives until exit by design so the next turn starts fast.

**Working set after the pill is 24.1 MB, close to the 25 MB idle budget.** Most of it is shared pages of the DLLs the
pill loads (comctl32 EDIT controls, the text-input framework, Credential Manager), which Windows trims under memory
pressure but not on an idle machine. The spec measures idle RAM after 10 voice turns, which P4–P5 will exercise; if
that lands over 25 MB, the first lever is not loading the pill's controls until text mode is used in a session
(already the case) and dropping the runtime thread after a long idle.

**Head frame p95 is 0.57 ms** with the 125 % head. Idle CPU was 15.6 ms per 60 s (one scheduler tick) in this run.

**Not measured yet (need a Mistral key):** first token ≤ 1.0 s p50, and the live log line for a cancel mid-stream.
Cancellation is covered by a test that drops a hanging turn within 30 ms of the cancel.

## P3 acceptance (spec §8)

| Criterion | Result |
|---|---|
| `Ctrl+Alt+T` opens a focused pill; typing, IME, Enter, Esc and ↑ recall work | Live (scratch hotkey): the pill opens focused with the placeholder, Enter sends, Esc hides it and retracts the head. Keys and recall are unit-tested on the real window. The Japanese IME has not been tried. |
| A streamed reply appears token by token; first token ≤ 1.0 s p50 | Streaming is tested against a mock server (Mistral and Anthropic). Live streaming and the latency need a key. |
| Esc mid-stream cancels within 30 ms and drops the request (log) | Unit test: the turn's future, holding the HTTP request, is dropped within 30 ms; the log line `turn N cancelled … ms after the request; its HTTP request was dropped` is written. Not yet seen live with a real stream. |
| Missing or invalid key → clear message with `--set-key`; key never logged | Live: "No API key is set. Run: sohi.exe --set-key mistral". A rejected key says to set it again. `--set-key` piped a test key; the log never contained it (grep), and the credential was deleted afterwards. |
| RAM after the pill is destroyed returns within 2 MB of pre-pill | Pass: +1.50 MB private (table above). |
